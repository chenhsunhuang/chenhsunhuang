## Selected Projects

### Decision Science & Optimization

**[KKBOX Churn Prediction & Causal Decision Framework](https://github.com/chenhsunhuang/kkbox-causal-decision-framework)**

Developed a subsidy decision framework integrating churn prediction, causal inference, and expected net benefit. Evaluated the credibility of individualized intervention recommendations and proposed a stratified randomized experiment.

**Methods:** XGBoost, LightGBM, Propensity Score Matching, Uplift Modeling, Experimental Design

**[MLB Schedule Optimization](https://github.com/chenhsunhuang/mlb-schedule-optimization)**

Co-developed a binary integer programming model for sports scheduling and travel cost optimization. Evaluated computational scalability across different team counts and matchup requirements.

**Methods:** Integer Programming, Mathematical Optimization, Gurobi, Computational Benchmarking

### Statistical Modeling & Machine Learning

**[Post-Promotion Demand Recovery Prediction](https://github.com/chenhsunhuang/post-promotion-demand-recovery)**

Co-developed a multi-stage promotion event detection and demand recovery prediction framework. Compared alternative recovery-time definitions and evaluated category-specific classifiers, with KNN achieving up to 79% accuracy and a macro-F1 score of 0.76.

**Methods:** Event Detection, Rolling Statistics, Target Engineering, Forward Feature Selection, KNN, XGBoost

**[Flight Delay Statistical Modeling](https://github.com/chenhsunhuang/flight-delay-statistical-modeling)**

Developed generalized linear models in R using a 200,000-record sample of U.S. domestic flights. Conducted interaction analysis, statistical model selection, and model diagnostics, and developed scenario-based risk sensitivity measures to support airline operational planning.

**Methods:** Logistic Regression, Generalized Linear Models, Likelihood Ratio Tests, AIC, Model Diagnostics, Sensitivity Analysis

**[Cross-Company News-Based Stock Movement Prediction](https://github.com/chenhsunhuang/cross-company-stock-movement-prediction)**

Co-developed a financial news NLP framework incorporating company-specific text filtering, weighted text representation, and statistical vocabulary selection. Independently redesigned the feature selection pipeline to restrict vocabulary construction and TF-IDF fitting to chronological training data. Examined accuracy–coverage trade-offs in cross-company prediction.

**Methods:** Chinese NLP, Chi-square, Mutual Information, TF-IDF, Linear SVM, Temporal Validation

### Database Engineering & Data Systems

**[Zoo Database Management System](https://github.com/chenhsunhuang/zoo-database-management-system)**

Co-designed a 12-table relational database and led synthetic data generation for zoo management operations. Co-implemented transaction management and concurrency control within a hybrid PostgreSQL and MongoDB architecture. Composite indexing achieved approximately 6–8× query speedups in team benchmarks.

**Methods:** Relational Database Design, Database Normalization, Synthetic Data Generation, SQL Optimization, Transaction Management, Concurrency Control, PostgreSQL, MongoDB
